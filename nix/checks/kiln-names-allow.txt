# Every place "M64" may still legitimately appear after the Kiln rename.
# nix/checks/kiln-names.nix strips each of these phrases from a line before
# looking for a residual "m64", so this file is the whole definition of what
# the old name is still allowed to mean.
#
# Two groups, and the distinction is the point:
#
#   1. Identifiers that merely CONTAIN "m64" and belong to somebody else.
#      xm64/ym64 are libdragon's tracker players (xm64player_*, .xm64, .ym64);
#      sm64 is Fast64's draw_layer key in the f3d_mat JSON that gltf_to_t3d
#      reads. A rename that touched either would break the build in a way
#      that looks like a codegen bug.
#
#   2. The ModRetro M64 console, which is a shipping product and keeps its
#      name. This is the group that makes the gate necessary: without it the
#      only way to keep these lines correct would be to remember, and the
#      whole reason the project renamed away from M64 is that one name for
#      two things does not survive contact with a sed.
#
# Adding a line here is a claim that this occurrence is NOT the engine. Say
# which group it is in.
