# tools/drive/intake.txt — the intake cutscene, reached in seconds.
#
#   ./dev drive petabyte-madness-debug tools/drive/intake.txt pm-intake
#
# INTAKE is the transformation: Horner, distraught, walks to a console, sits,
# types, stands, walks to the MRI, and the machine takes him. 14.5 s of
# keyframed camera over a skinned rig, and the shot most likely to need
# re-framing — which is why it gets its own script.
#
# ── Why this is not tools/drive/intro.txt ──────────────────────────────
# intro.txt plays the game: boot splash, title, a 12 s attract idle, file
# select, a narration crawl, a walk across the lab to the MRI. Roughly ninety
# seconds before INTAKE starts, and that is the correct thing for a script whose
# job is "capture every screen in order". It is the wrong thing for iterating on
# one shot, and iterating on one shot by editing forced transitions into
# pm_screens.c is what this replaces (see the debug jump menu's comment there).
#
# The debug ROM opens on a jump menu. INTAKE is the sixth entry:
#   TITLE FILE NARRATION LAB_CINE LAB *INTAKE* CREDITS SUB BEACH PLAY
#
# ── Read the pixel statistics, not the PNGs ────────────────────────────
# A dim underwater lab upscaled into a large screenshot reads as "black" to the
# eye when the picture is right there; that misread has already cost this
# project real time (CLAUDE.md, "Screenshots"). Every shot below prints colour
# histograms and a non-black percentage. Trust those.
#
# ── And turn the spatial overlay on ────────────────────────────────────
# C-Up + C-Down cycles pm_debug's layers (pm_debug.h). The `cam` set draws the
# shot's keyframe path and each key's sightline, which is the only way to see
# the Catmull-Rom overshoot the INTAKE_KEYS midpoints exist to suppress — as a
# table of eye coordinates it is invisible.
