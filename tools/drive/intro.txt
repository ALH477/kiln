# tools/drive/intro.txt — every screen PetaByte Madness has, in order,
# captured. Run with: ./dev drive petabyte-madness tools/drive/intro.txt
#
# The waits are the screens' own durations, read off the source rather
# than guessed, so a shot lands mid-screen instead of on a transition:
#
#   kiln_splash.c   T_END 3.8 s          the boot logo
#   pm_screens.c   ATTRACT_IDLE 12 s    title gives up and starts the reel
#   pm_demo.c      flyover 30 s, lab 10 s, centaur 8 s (locked)
#   pm_demo.c      lab_cine 6 s
#   pm_intake.c    PH_FRAMES/PH_FPS = 14.53 s
#   pm_arrival.c   sub 12 s, beach B_END 13 s
#
# Read the PIXEL STATISTICS each shot prints, not the PNGs. A 320x240
# horror title upscaled into a big screenshot reads as "black" to the eye
# when the picture is right there — that misread has already cost this
# project real time (CLAUDE.md, "Screenshots").
